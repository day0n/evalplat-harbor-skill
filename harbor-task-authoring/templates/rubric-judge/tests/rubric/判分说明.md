## 细则 → 程序的对应

| 细则内容 | 程序做法 |
|---|---|
| R1–R4 分值 30/40/20/10，满分 100 | `items.json` 逐项登记，合计 100 |
| 没有明列部分档的行只取全分或零分 | `all_or_nothing`：未达满分一律记 0 |
| R2 必要前提 R1 | `requires: ["R1"]`；R1 未得满分时 R2 记 0 |
| 编造数据每处扣 5 分，扣自总分 | 扣分判定调用一次判分模型；`deduct_group: "S"` |
| 四舍五入两位 | `round: 2` |

判分模型 gpt-6.1-sol，思考强度 max；不可用时不写 reward。
